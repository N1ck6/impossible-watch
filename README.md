# Word Clock v2

Часы в стиле **Word Clock** с текстовым и цифровым отображением времени.

## Возможности

- **Текстовый режим** — время отображается словами (IT IS TWENTY FIVE PAST TWO)
- **Цифровой режим** — отображение часов, минут или секунд крупными цифрами из букв
- **12/24-часовой формат** — переключается кнопкой или горячей клавишей
- **AM/PM индикация** — в текстовом режиме при 12-часовом формате; при 24-часовом пропадает
- **Индикатор режима** — буквы H/M/S в верхней строке показывают текущий режим цифрового отображения
- **Перетаскивание** — окно перемещается за любую часть (рамку или сетку)
- **Ресайз за углы** — изменение размера окна за угловые зоны (мин 220×160, макс 800×600)
- **Системный трей** — иконка в трее с пунктом выхода, клик показывает/скрывает окно
- **Поверх всех окон** — всегда видимы
- **Без рамки окна** — минималистичный вид
- **Анимация выхода** — поэтапное затухание букв + fade-out окна
- **Сохранение настроек** — позиция и размер окна сохраняются между запусками

## Управление точками (4 точки по углам)

| Кнопка | Режим | Действие |
|--------|-------|----------|
| **Левая верхняя** | Горит = текст | Переключение между текстом и цифрами |
| **Левая нижняя** | Горит = минуты | В цифровом режиме: показывает минуты / повторное нажатие = часы |
| **Правая верхняя** | Горит = 12ч | Переключение 12/24-часового формата |
| **Правая нижняя** | Горит = секунды | В цифровом режиме: показывает секунды / повторное нажатие = часы |

> В текстовом режиме нижние кнопки отключены и не горят.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Space` | Переключение текст/цифры |
| `Ctrl+Q` | Выход с анимацией |

## Дизайн (по фото)

- **Фон**: глубокий чёрный `#0a0a0a`
- **Неактивные буквы**: тёмно-серый `#1a1a1a` (почти невидимый)
- **Активные буквы**: яркий бело-голубой `#e0f7ff` с glow-эффектом
- **Ободок**: тонкий серебристый `#888888`, 1px
- **Шрифт**: sans-serif, medium weight, крупный
- **Буквы**: без обводок/рамок, плотная сетка без промежутков
- **Точки-кнопки**: маленькие, тусклые, в углах

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск из исходников

```bash
python main.py
```

## Сборка в EXE

### Через скрипт:
```bash
python build.py
```

### Вручную:
```bash
pyinstaller main.py --name WordClock --noconfirm --clean --windowed --onedir
```

Готовое приложение будет находиться в папке `dist/WordClock/`.  
Запускать файл `dist/WordClock/WordClock.exe`.

## Структура проекта

```
word_clock/
├── main.py           # Точка входа
├── clock_window.py   # Главное окно (рамка, трей, кнопки, drag, resize, анимация)
├── clock_face.py     # Виджет сетки букв (масштабирование, glow)
├── time_logic.py     # Логика времени и координат подсветки (цифры 5×7)
├── config.py         # Константы, стили, новая сетка ITLISMHAMPM
├── requirements.txt  # Зависимости
├── build.py          # Скрипт сборки
├── build.bat         # Альтернатива для Windows
└── README.md         # Описание
```

## Примечания по безопасности

- Сборка выполняется через **PyInstaller** в режиме `--onedir` (папка), что минимизирует ложные срабатывания антивирусов.
- Используются только стандартные вызовы PyQt6, нет обфускации, `eval` или подозрительных операций.
- Для ещё меньшей вероятности срабатывания антивируса рекомендуется подписать `.exe` сертификатом (требуется при массовом распространении).
