# Word Clock

Квадратные буквенные часы с золотой рамкой — модуль-виджет для панели продуктивности. Показывают время текстом или числами, запускаются и закрываются извне через Отдельный менеджер модулей.

Часы работают как отдельный процесс-модуль, которым управляет внешний менеджер, — можно встроить в любое рабочее пространство продуктивности рядом с другими такими же модулями.

Золотая рамка работает как ambient-таймер: полный оборот по периметру равен одной минуте, рамка "стирается" по часовой стрелке от левого верхнего угла и обнуляется в начале каждой минуты.

<!-- СКРИН 3: момент клика по циферблату — по центру видна полупрозрачная

     Вставить третьим, чтобы показать фичу паузы. -->

Клик по самому циферблату ставит часы на паузу — время и рамка замирают.

## Как интегрировать в своё приложение

Часы не запускаются напрямую — их жизненным циклом управляет `module_manager.py`, управляемые модули находятся в `modules.json`.

Из основного приложения достаточно вызывать менеджер как подпроцесс:

```bash
python module_manager.py clock start   # открыть (или поднять уже открытое окно наверх)
python module_manager.py clock stop    # закрыть с анимацией затухания
python module_manager.py clock status  # проверить, запущены ли часы
python module_manager.py clock toggle  # открыть/закрыть в зависимости от состояния
```

Python:

```python
import subprocess
subprocess.run(["python", "module_manager.py", "clock", "start"], cwd="/path/to/word_clock")
```

cmd:

```bash
python /path/to/word_clock/module_manager.py clock start
```

Повторный `start` не открывает второе окно: если часы уже запущены, менеджер просто выводит их окно поверх остальных.

Сам менеджер висит в системном трее для ручного включения/выключения модулей без основного приложения:

```bash
python module_manager.py        # то же самое, что: python module_manager.py tray
```

Чтобы добавить новый модуль с той же системой запуска/остановки — допишите его в `modules.json` и реализуйте в самом модуле приём команд `"stop"` / `"focus"` через `QLocalServer` на имени сокета из конфига (см. `clock/main.py` как референс).

## Функционал и использование

- **Текстовый / цифровой режим** — левая верхняя точка или клавиша `Space`.
- **Часы / минуты / секунды** (только в цифровом режиме) — циклическое переключение: левая нижняя точка листает вперёд (Ч → М → С), правая нижняя — назад. Текущий режим всегда виден как горящая буква H/M/S над числами.
- **12 / 24-часовой формат** — правая верхняя точка. AM/PM показывается только в 12-часовом формате.
- **Пауза** — клик по циферблату замораживает часы и золотую рамку-таймер, повторный клик снимает паузу.
- **Перетаскивание** — за любую часть окна.
- **Ресайз за углы** — форма всегда остаётся квадратом, буквы масштабируются в реальном времени прямо во время перетаскивания угла.
- **Сохранение состояния** — позиция, размер и режим отображения между запусками.
- **Ctrl+Q** — закрытие с анимацией (то же самое, что `module_manager.py clock stop`).

### Установка

```bash
pip install -r requirements.txt
python clock/main.py     # прямой запуск в обход менеджера — для разработки
```

### Сборка в exe

```bash
python build.py
```

Соберёт `dist/WordClock/` и `dist/ModuleManager/`. После сборки положите `modules.json` рядом с `ModuleManager` и при необходимости поправьте в нём `"script"` на путь к собранному `WordClock` (по умолчанию менеджер запускает `clock/main.py` через Python — это ок для разработки, но требует Python в системе, где будет работать менеджер).
