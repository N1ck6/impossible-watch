# Productivity Modules

Набор фреймлесс-виджетов для панели продуктивности: часы, трекер привычек, блокировщик отвлеченийУправление происходит через общий `module_manager.py`.

## Как это устроено

Модули прописаны в `modules.json`. Каждый модуль слушает свой `QLocalServer` и понимает две команды: `"stop"` (закрыть) и `"focus"` (поднять окно наверх).

```bash
python module_manager.py <module> start   # открыть (или поднять уже открытое окно наверх)
python module_manager.py <module> stop    # закрыть
python module_manager.py <module> status  # проверить, запущен ли
python module_manager.py <module> toggle  # открыть/закрыть в зависимости от состояния

python module_manager.py                  # трей-фоллбэк: ручное вкл/выкл всех модулей
```

где `<module>` — `clock`, `habits` или `focus_guard`.

Добавить новый модуль — дописать его в `modules.json` (`label`, `script`, `socket_name`) и реализовать приём `"stop"`/`"focus"` в самом модуле (см. любой `<module>/main.py` как референс).

### Установка

```bash
pip install -r requirements.txt
python clock/main.py         # прямой запуск в обход менеджера — для разработки
python habits/main.py
python focus_guard/main.py   # требует прав администратора/root, см. ниже
```

### Сборка в exe

```bash
python build.py
```

Соберёт `dist/WordClock/`, `dist/HabitTracker/`, `dist/FocusGuard/`, `dist/ModuleManager/`. После сборки положите `modules.json` рядом с `ModuleManager` и поправьте в нём пути `"script"` на собранные exe.

## Word Clock

<!-- СКРИН 1: текстовый режим, крупный план — золотая рамка, свечение букв -->

Квадратные буквенные часы. Показывают время текстом или числами; клик по циферблату переключает паузу Pomodoro-таймера.

<!-- СКРИН 2: цифровой режим с кнопками H/M/S -->
<!-- СКРИН 3: панель настроек Pomodoro (Session/Break/Repeat + Start) -->

- **Текст / цифры** — левая верхняя точка или `Space`.
- **Часы / минуты / секунды** — кнопки `H` `M` `S` внизу (вне Pomodoro).
- **12 / 24ч** — правая верхняя точка.
- **Pomodoro** — значок `⏱` открывает настройки (Session/Break/Repeat), после старта золотая обводка = прогресс-бар текущей стадии (один оборот = 100%), лайм — перерыв. Во время работы `H/M/S` заменяются на `⏭` (пропустить стадию).
- **Ресайз за углы** — всегда квадрат, масштабирование в реальном времени.

## Habit Tracker

<!-- СКРИН 4: сетка привычек, тёмный терминальный стиль, зелёное свечение -->

Сетка-календарь в стиле терминала (чёрный фон, monospace, "matrix"-зелёный). Каждая клетка — день; клик по клетке — отметить/снять выполнение текущей привычки. Чем длиннее серия подряд выполненных дней, тем ярче свечение клетки (с порогами на 3 и 7 дней).

- `▸` (левый верхний угол) — переключиться на следующую привычку.
- `⚙` (правый верхний угол) — добавить/удалить привычку.
- Данные хранятся в `habits/habits_data.json` рядом со скриптом.

## Focus Guard

<!-- СКРИН 5: панель Focus Guard в состоянии IDLE -->
<!-- СКРИН 6: панель в состоянии ACTIVE (красная рамка, обратный отсчёт) -->

Блокировщик отвлечений: на время сессии отключает выбранные сайты и периодически сворачивает окна выбранных приложений.

**Как это работает технически**:

- Блокировка сайтов — это редактирование системного hosts-файла. Требует прав администратора (Windows) или root/sudo (Linux/macOS) на запись файла. Никакой эскалации прав модуль сам не делает — без прав просто покажет ошибку.
- Сворачивание приложений — best-effort и платформозависимо: Windows нужен `pywin32`+`psutil`, Linux — системная утилита `wmctrl`, macOS — доступ Accessibility для `System Events`. Это дополнительный, не единственный уровень защиты — hosts-блокировка сайтов работает независимо от него.
- **Антисофтблок**: пока сессия активна, список сайтов/приложений нельзя редактировать, а кнопка "Стоп" требует ожидания (`STOP_CONFIRM_SECONDS`, по умолчанию 20с) прежде чем подтверждение станет доступно — это защита от импульсивного "выключу на секунду". Команда `module_manager.py focus_guard stop` во время активной сессии тоже не снимает блок мгновенно — она просто поднимает окно наверх, чтобы пройти обычный флоу подтверждения.
- **Аварийный выход** — глобальная горячая клавиша `Ctrl+Alt+Shift+F12` (см. `EMERGENCY_HOTKEY` в `focus_guard/config.py`) снимает блокировку немедленно и без подтверждения, в любой момент, даже если окно не в фокусе. Это осознанный, единственный способ обойти антисофтблок — на случай реальной необходимости (а не просто "передумал").
- **Самый крайний фоллбэк**, если ничего из вышеперечисленного недоступно (например, не установлен пакет `keyboard`): блокировка — это буквально несколько строк между маркерами в hosts-файле, их можно удалить вручную в любом текстовом редакторе с правами администратора. Путь к файлу: `C:\Windows\System32\drivers\etc\hosts` (Windows) или `/etc/hosts` (Linux/macOS).
- Если процесс Focus Guard аварийно завершится во время активной сессии, hosts-блок **останется** (это осознанное поведение, а не баг — иначе просто "убить процесс" снимало бы блокировку). При следующем запуске модуль это обнаруживает и возобновляет мониторинг приложений.

Настройки хранятся в `focus_guard/focus_guard_data.json`.
